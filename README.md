# yolo-world-traffic-safety
Acknowledgements and Upstream Source

This repository contains my deep learning coursework on adapting YOLO-World to traffic-safety object detection, completed from 23 to 30 June 2025.

The implementation is based on the official YOLO-World project:

Original repository: https://github.com/AILab-CVC/YOLO-World

Paper: Tianheng Cheng, Lin Song, Yixiao Ge, Wenyu Liu, Xinggang Wang, and Ying Shan. “YOLO-World: Real-Time Open-Vocabulary Object Detection.” CVPR, 2024.

My coursework involved studying and reproducing the model workflow, configuring traffic-domain fine-tuning experiments, and analysing detection results. The original YOLO-World architecture and upstream implementation are credited to their respective authors.

This repository is an independent coursework adaptation and is not an official release of YOLO-World.

Availability and Reproducibility

Large datasets, model checkpoints, and temporary training outputs are not included. The original execution environment has not yet been revalidated; the uploaded code and results are retained from the coursework experiments.
